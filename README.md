A modern, responsive chatbot UI designed for AI-powered conversational systems. This project focuses on creating an intuitive and visually appealing interface that can be integrated with LLMs, RAG pipelines, or agent-based workflows.

## Features

- Interactive chatbot interface with user & bot message bubbles
- Dynamic welcome screen with example queries
- Expandable sidebar with navigation controls
- Smooth animations and transitions
- Fully responsive design
- File attachment UI support (frontend ready)
- Scrollable chat with custom styling

## Tech Stack

- HTML5
- CSS3 (Flexbox, animations, gradients, responsive design)
- JavaScript (for interactivity - if added)

## Architecture Overview

- **Sidebar Navigation**: Collapsible menu for future feature extensions
- **Chat Area**:
  - Header with branding
  - Chat box with dynamic messages
  - Welcome screen for onboarding
- **Input Area**:
  - Text input + send button
  - File attachment placeholder

## UI Highlights

- Glassmorphism + gradient-based design
- Smooth hover animations
- Custom scrollbar styling
- Mobile-responsive layout

## Integration Ready

This UI can be easily integrated with:
- OpenAI / LLM APIs
- RAG pipelines
- n8n workflows
- Backend frameworks (Flask, Node.js)
